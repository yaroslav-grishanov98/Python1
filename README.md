# Django Project: PythonProject1

## Описание

Это Django-проект с использованием Django REST Framework (DRF) и базой данных PostgreSQL.  
Проект содержит приложения:
- `users` — кастомная модель пользователя с авторизацией по email, дополнительными полями (телефон, город, аватарка).
- `materials` — модели Курсы и Уроки с CRUD API.

## Требования

- Python 3.10+  
- PostgreSQL  
- Виртуальное окружение (рекомендуется)
